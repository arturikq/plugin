# Zodiac Info Plugin

**Автор:** Нигматуллин Артур Алмазович М3109

## Описание
Плагин для **VS Code**, который показывает гороскоп на русском языке по выбранному знаку зодиака.  
Все данные берутся из локального JSON-файла, поэтому плагин работает **без интернета**.  

## Возможности
- Выбор знака зодиака через всплывающее меню.
- Показ гороскопа в виде всплывающего уведомления.
